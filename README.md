# Convert2Any desktop

Official installers for [Convert2Any](https://convert2any.app/).

Download the newest version for your computer from [Releases](https://github.com/tutkutashkan/convert2any-releases/releases). Each release names the platforms it is for. This link always downloads the newest Mac version:

https://github.com/tutkutashkan/convert2any-releases/releases/latest/download/Convert2Any-macos-arm64.zip

## Mac

Signed and Apple notarized app for Apple Silicon Macs. Open the downloaded ZIP and drag Convert2Any to Applications.

The app is small and includes the converters for data, PDF editing and many everyday formats. Some conversion types use an optional pack, such as the media pack for video and audio. The app asks before downloading one, checks it, and keeps it for offline use.

## License

Every tool works for 3 days with no account or payment details. After that, conversions need a one-time lifetime license, which works on up to three computers. In the app, use **Buy lifetime license**, or buy from the [website pricing page](https://convert2any.app/pricing). If you already bought a license, enter your key and choose **Activate license**. If you lost it, enter your purchase email under **Lost your key?** Each release lists a SHA-256 checksum for every file so you can verify the download.

For help, contact [support@convert2any.app](mailto:support@convert2any.app).
